## 一、 最新数据库变更通知（必须知晓）

### 1. 新增字段说明
- **表**：`sys_user`
- **字段**：`address varchar(255) COMMENT '收货地址'`
- **说明**：补充了用户收货地址字段，已填充大量真实感测试数据（如“南昌大学前湖校区X栋X室”等）。前端下单展示，后端读写请务必带上此字段。

### 2. 触发器定义及行为说明（后端请避免重复写逻辑！）
触发器脚本已上传至 `db/03_triggers.sql`，包含以下三个：

| 触发器名称 | 触发事件 | 行为说明 | 后端注意事项 |
| :--- | :--- | :--- | :--- |
| `trg_order_complete_update_goods` | `orders` 表 UPDATE 后 | 当订单状态变为 **3（完成）** 时，自动将对应商品的 `goods_status` 改为 **3（已售出）** | **严禁**在 Service 层重复写“更新商品为已售出”的代码，避免双重更新冲突 |
| `trg_user_ban_off_goods` | `sys_user` 表 UPDATE 后 | 当用户 `status` 变为 **1（封禁）** 时，自动将其名下所有状态为 0/1 的商品强制变为 **2（下架）** | 后端只做权限校验和状态变更，不要重复下架商品 |
| `trg_prevent_unfinished_evaluate` | `evaluate` 表 INSERT 前 | 拦截对非 **3（完成）** 订单的恶意评价，数据库抛出异常：“只能对已完成的订单进行评价！” | 后端应提前校验，但即使漏了校验，数据库也会兜底拦截 |
