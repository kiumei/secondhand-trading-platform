# 校园二手交易平台数据库设计项目
> 本项目为校园二手交易平台数据库设计，面向在校学生实现校内闲置物品流转，包含完整数据库设计文档、E‑R模型、概念模型、物理模型、数据字典、表结构、约束设计。

## 项目简介
随着校园信息化发展，学生存在大量教材、生活用品、数码配件等闲置物品，QQ群、朋友圈等传统二手交易渠道存在信息分散、查找低效、交易无保障等痛点。
本项目完成**校园二手交易平台数据库系统设计**，对用户、商品分类、商品、订单、评价、私信、举报业务数据统一管理，支撑上层应用实现商品发布审核、商品检索筛选、订单交易、用户评价、私信聊天、违规举报处理等业务，促进校园闲置资源循环利用。

### 系统角色
1. **普通学生用户**：注册登录、发布二手商品、浏览筛选商品、下单交易、订单管理、商品评价、发送私信、提交举报。商品提交后需管理员审核才可对外展示。
2. **管理员**：商品审核（通过/驳回并填写驳回理由）、商品分类维护、处理用户举报工单。

## 数据库信息
- 数据库：`MySQL 8.0`
- 存储引擎：`InnoDB`
- 字符集：`utf8mb4`
- 支持：事务、外键约束、定期备份

## 数据库表结构
共7张数据表，全部满足**第三范式3NF**，消除部分依赖、传递依赖，降低数据冗余。

|表名|中文名称|说明|
|----|--------|----|
|`sys_user`|用户信息表|存储学生与管理员账号信息，区分角色权限|
|`category`|商品分类表|二手商品分类（教材、数码、生活用品等）|
|`goods`|商品信息表|用户发布的二手商品，包含审核状态、驳回原因|
|`orders`|订单信息表|用户交易订单，记录买家、卖家、对应商品|
|`evaluate`|评价信息表|订单完成后用户对商品的评分评价|
|`message`|私信信息表|用户之间聊天私信消息|
|`report`|举报信息表|用户对违规商品的举报记录，管理员处理工单|

### 核心字段约束说明
1. **实体完整性**：每张表设置主键PRI，主键非空唯一。
2. **参照完整性**：通过外键FK完成表关联，保证数据引用合法。
3. **自定义业务约束**
    - 用户角色：`0=普通学生`，`1=管理员`
    - 商品状态：`0未售出，1已售出，2下架，3待审核，4驳回`
    - 订单状态：`0待付款，1代发货，2待收货，3完成，4取消，5售后`
    - 评价评分：取值范围`1~5`整数

## 模型说明
1. **数据流图**：顶层数据流图、0层细化数据流图，描述用户、管理员与平台之间数据流动；
2. **E‑R概念模型**：7大实体：用户、商品分类、商品、订单、评价、私信、举报；实体间为1:n一对多关系；
    - 用户 →(发布)→ 商品：一个用户发布多条商品，商品归属一个发布者
    - 商品分类 →(包含)→商品：一个分类下多个商品
    - 用户(买家) →(下单)→订单：一个买家多条订单
    - 订单绑定唯一商品；商品可产生多条订单
    - 用户撰写评价，商品接收多条评价
    - 私信：发送人、接收人两个用户关联
    - 举报：用户发起举报，针对某一件商品

## 安全设计
1. **角色权限隔离**：普通用户、管理员权限分离；
2. **密码加密存储**：用户密码禁止明文入库；
3. **参数化查询**，防范SQL注入攻击。

## 主要业务流程
1. **用户注册登录**：区分学生/管理员角色；
2. **发布商品**：学生填写商品信息提交 → 状态变为待审核，等待管理员审核；管理员可通过/驳回填写驳回原因；审核通过商品对外展示；
3. **商品浏览检索**：按分类、价格筛选商品；
4. **下单交易**：买家下单生成订单，记录买卖双方；
5. **评价**：订单完成后用户提交评分+文字评价；
6. **私信沟通**：买卖双方发送私信聊天；
7. **举报处理**：用户提交商品举报，管理员查看并处理举报工单。

## 使用说明
1. 本地安装MySQL8.0，创建数据库；
2. 执行`secondhandtrasaction.sql `脚本完成全部数据表创建,需要检查编码问题，在不同的软件上可能会出现中文乱码问题；
3. 执行初始化脚本导入分类等基础数据，需要做初步测试，保证数据库数据表逻辑无误；
4. 上层业务应用对接数据库，实现业务功能。
5. 对于sws文件，需要使用PowerDesigner查看对应的数据流图和模型，其中sql通过PDM导出。
## 补充说明
> 本项目为，仅完成数据库层设计，不含前后端业务代码；可基于该数据库结构开发SpringBoot、SSM等后端服务。
