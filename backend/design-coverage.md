# 原始系统设计的实现覆盖

本次核对依据是系统设计目录的 Word 文档、README 和 PowerDesigner PDM，参照目前后端代码。结论：七类主要业务和 Word 明确列出的后端功能已有实现，但没有覆盖全部模型扩展，也尚未完成数据库与前端验收。

## 已有后端实现

Word 的需求分析、逻辑结构设计与 README 所列的注册登录、商品发布和审核、分类维护、分类与价格筛选、订单管理、评价、私信、举报处理，均已有接口和 MyBatis SQL。身份权限、密码哈希和参数化查询也已实现。已有测试使用数据库访问替身；实际数据库执行效果尚待验证。

## 不应误算成原设计必需项

- 商品封面：Word 商品数据字典与 PDM 没有该字段。cover_url 和封面上传是此前后端计划提出的扩展，本轮没有加入。
- 真实支付平台接入：原设计有支付状态，没有支付渠道或网关方案；当前使用模拟支付。
- 简单统计接口：来自后端课程展示建议，不是原始 Word 明确列出的功能。
- 收藏、求购、SMTP、搜索联想等：主要来自前端 README 或扩展设想，不能直接等同于系统设计同学的原始需求。

表结构按此前确认的修正口径及 Word 数据字典映射，订单状态采用 PDM。未逐项实现 PDM 中与 Word 不同的字段，例如分类层级、排序字段、支付与完成时间；这属于选定实施基线后的差异，不能声称所有模型字段均已覆盖。
